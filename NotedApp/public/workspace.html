Workspace Controls

Desktop controls

  • Use the module buttons on the left to add a Kanban board, Flowchart, Note, or Picture.
  • Drag a module by its header to move it around the canvas.
  • Kanban: Add cards to columns, drag cards between columns, and click a card to view, edit, or delete it.
  • Flowchart: Add objects, drag shapes to arrange them, double-click a shape label to rename it, use Connect to link shapes, and drag the corner to resize the chart.
  • Note: Click in the note to edit; changes save automatically. You can also use Save.
  • Picture: Add an image from a URL.
  • Use the pencil button to rename a module and the trash button to delete it.
  • Scroll the canvas to explore it; hold Ctrl and use the mouse wheel to zoom the view.

Mobile controls

  • Tap a module button in the top toolbar to add a Kanban board, Flowchart, Note, or Picture.
  • Drag a module by its header to move it around the canvas.
  • Kanban: Tap + Add Card to add a card, tap a card to edit or delete it, and drag cards to move them between columns.
  • Flowchart: Add objects, drag shapes to arrange them, double-tap a shape label to rename it, use Connect to link shapes, and drag the corner to resize the chart.
  • Note: Tap in the note to edit; changes save automatically. You can also use Save.
  • Picture: Add an image from a URL
  • Use the pencil button to rename a module and the trash button to delete it.
  • Swipe or scroll the canvas to move around it.
