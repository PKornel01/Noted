## 🚀 Quick Start Options

### Option 1: Frontend Only (Instant)
```bash
1. Open index.html in browser
Done! App is working.
```

### Option 2: With Backend (15 minutes)
```bash
1. npm install
2. mysql -u root -p < kanban.sql
3. cp .env.example .env
4. Edit .env with your database password
5. npm start
Done! Server is running at http://localhost:3000
```

**See [BACKEND_SETUP.md#quick-start](BACKEND_SETUP.md#quick-start) for detailed steps**

### Option 3: Full Integration (45 minutes)
```bash
1. Complete Option 2 (above)
2. Read BACKEND_INTEGRATION.md
3. Copy helper functions to script.js
4. Modify 6 existing functions
5. Test API calls
Done! Your app uses the database.
```
