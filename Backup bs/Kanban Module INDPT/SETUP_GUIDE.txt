## 🚀 How to Use

### For Frontend-Only Users
```
Open index.html → Start creating boards and cards
No setup needed!
```

### For Backend Setup
```
1. Read: BACKEND_SETUP.md#quick-start (5 min)
2. Run: npm install
3. Run: mysql -u root -p < kanban.sql
4. Create: .env from .env.example
5. Run: npm start
6. Open: http://localhost:3000
Done! Your backend is running.
```

### For Frontend-Backend Integration
```
1. Complete: Backend Setup (above)
2. Read: BACKEND_INTEGRATION.md
```
